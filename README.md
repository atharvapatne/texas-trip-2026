# Texas x F1 trip site (toon edition)

All files sit at one level (no folders). Start page: index.html (pick who you are), then home.html.

## Optional: turn on the shared board (so everyone sees the same points, photos and notes)
In GitHub: Add file > Create new file. In the name box type exactly:  netlify/functions/trip.mjs
(typing the slashes makes the folders). Paste in the contents of COPY-ME-trip-function.txt and commit.
Without this the site still works, but each phone keeps its own data.

## Things you can change
- hero.jpg: add a wide landscape photo with this exact name and it replaces the cartoon car on the home page.
- cocktails.js: the cocktail menu. Photos are drink-jager.jpg, drink-kokam.jpg, drink-cucumber.jpg, drink-tamarind.jpg.
- app.js: the TRIP block near the top has address, phone, plate and Wi-Fi.
